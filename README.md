
## Home Energy System Monitor

Python program analyzes, classifies and calculates energy consumption readings on house-hold devices and provides a detailed summary report.

## Prerequisites needed:

Python 3.14+ (updated and pre-installed)

## Running the Program:

1. Clone the repository: 
```bash
git clone https://github.com/hs9400/repo1.git
```

2. Navigate to directory: 
```bash
cd repo1
```

3. Run the program using Python:
```bash 
python gcis.py
```

## Interactions:
When prompted, enter details regarding device type, energy consumption and electricity rate in appropriate units.

## Program Output:

Program should display:
1. Base range, power consumption, alerts (if necessary), calculated energy cost and troubleshooting feedback for each reading.
2. Summary report consisting of: Total number of readings, Number of High, Normal and Critical readings, Total energy consumption, Total calculated cost, and the device with highest energy consumption.
